## 📝 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git (for cloning the repository)
- Optional: Python 3 or Node.js (for local server)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Julia-Cameron/realestate-portfolio-site.git
   cd realestate-portfolio-site
   ```

2. **Open in your browser**
   
   **Option A: Direct**
   ```bash
   # Simply open the file
   open index.html
   # or on Windows
   start index.html
   ```

   **Option B: Local Server (Recommended)**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # or using Node.js
   npx http-server
   ```
   Then visit `http://localhost:8000` in your browser

### Customization

To customize the portfolio for your own properties:
- Edit `index.html` to update property listings and contact information
- Modify `style.css` to adjust colors, fonts, and branding
- Update image paths to point to your property photographs
- Modify the hero section and navigation to reflect your branding
